Upload your client workbook

Imports run in the background. Upload an .xlsx workbook up to 10 MB and 25,000 rows, then follow its progress on the results page.

Include reg_number and full_name headers. Reg. No is required on every row; a name is required for new clients.

  • Existing Reg. No: update nonblank fields on the same client record.
  • New Reg. No: create a new client.
  • Blank cells: keep current values. A numeric zero is an explicit value.
  • Duplicate Reg. No or invalid data: skip the affected rows and list the reasons below.

Column order does not matter. Dates: DD/MM/YYYY or YYYY-MM-DD. If the workbook has an Updates sheet, only that sheet is imported; otherwise the active sheet is used. Review and Instructions sheets in the prepared workbook are not imported.
